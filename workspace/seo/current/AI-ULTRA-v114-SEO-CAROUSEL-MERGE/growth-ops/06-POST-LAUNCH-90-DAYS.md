# Post-launch 90-day execution

## Days 0–7
- Verify production domain in Yandex Webmaster and Google Search Console.
- Submit production sitemap.
- Confirm Metrica events and paid-traffic UTMs.
- Check index/noindex/canonical on a representative sample.
- Inspect logs/coverage for unexpected crawler blocks.
- Publish approved team/portfolio evidence available at launch.

## Days 8–30
- Launch only priority commercial campaigns.
- Pair each SMM/Yandex Direct campaign with a relevant PDF/checklist offer.
- Publish 2–4 deep editorial pieces from real questions/projects.
- Begin Pressfeed monitoring and targeted expert answers.
- Create outreach list for first research asset.
- Record baseline: search impressions, Moscow queries, qualified leads, conversion rate.

## Days 31–60
- Publish first Research Lab asset if data quality is sufficient.
- Pitch tailored versions to 10–30 relevant journalists/editors/partners.
- Publish one technical and one business angle on external platforms where editorial rules permit.
- Start first portfolio-to-case conversion cycle.
- Evaluate which lead magnet generates qualified leads, not just downloads.

## Days 61–90
- Update weak pages using real query/behavior data.
- Add first high-value free utility only if core performance is stable.
- Produce video for the highest-converting service/case first.
- Publish second research/benchmark or update first dataset.
- Build quarterly editorial/research calendar from observed demand.

## Do not do in first 90 days
- create hundreds of new city/service permutations;
- buy bulk backlinks;
- publish daily generic AI news;
- rebuild the visual engine without a measured reason;
- confuse traffic volume with qualified demand.
