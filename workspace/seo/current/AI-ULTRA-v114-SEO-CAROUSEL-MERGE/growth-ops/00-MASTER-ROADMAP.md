# AI ULTRA — GROWTH OPS MASTER ROADMAP

## Mission
Build AI ULTRA as two systems at once:
1. a conversion-focused commercial site for Moscow / Russia / CIS;
2. a long-term reference resource that earns citations, backlinks, branded demand and AI-search visibility.

The visual carousel is a separate presentation layer. Do not merge it into this package until the carousel engine is frozen.

## Current frozen asset
- v112 semantic/content core remains the search foundation.
- 212 production-indexable pages after release.
- 191 intentional noindex / legacy / service pages.
- 0 production orphan pages in the v112 release simulation.
- 40 indexable blog materials.

## Sequence
### Phase 0 — NOW, before visual engine is finished
- Preserve SEO core.
- Prepare portfolio intake system.
- Prepare lead-magnet system.
- Prepare Research Lab backlog and methodology templates.
- Prepare measurement/event taxonomy.
- Prepare editorial/outreach map.
- Prepare release checklist.

### Phase 1 — FIRST PUBLIC RELEASE
- Freeze carousel engine.
- Merge semantic HTML with final Three.js/raster presentation layer.
- Keep all critical copy and ordinary HTML links accessible without relying on WebGL.
- Run desktop/mobile performance and accessibility QA.
- Move from temporary domain to approved production domain using release-production.py.
- Verify Yandex Webmaster, Google Search Console, Yandex Metrica and conversion goals.

### Phase 2 — FIRST 30 DAYS
- Submit sitemaps and inspect indexing coverage.
- Publish portfolio/case pages from real work.
- Launch SMM and Yandex Direct only with campaign-specific landing + lead magnet.
- Start expert distribution: VC.ru / Habr / RB.RU / Workspace / Cossa / Pressfeed where relevant.
- Record baseline rankings, branded queries, leads and assisted conversions.

### Phase 3 — DAYS 31–90
- Publish first proprietary research asset.
- Publish at least 2–4 deep editorial pieces per month based on real questions/data.
- Convert portfolio projects into case study + technical note + editorial pitch + social proof.
- Earn citations through outreach to journalists/partners rather than link exchanges.
- Build first downloadable tools/resources only after core site is stable.

### Phase 4 — 3–12 MONTHS
- Research cadence: one substantial data asset every 1–2 months where data quality permits.
- Expand industry pages only where real expertise/cases justify them.
- Create video demos for high-intent services and portfolio.
- Build free utilities/calculators that deserve repeat visits and links.
- Develop branded queries and direct traffic.

### Phase 5 — 12–36 MONTHS
- AI ULTRA Research Lab becomes a cited primary source.
- Maintain living benchmarks rather than one-off articles.
- International/English layer only after Russian core has evidence and operating rhythm.
- Build partner ecosystem, media relationships, speaking/conference footprint and open technical assets.

## Non-negotiable principles
- No fabricated office, reviews, cases, numbers or research samples.
- No doorway city clones.
- No paid-link exchange strategy.
- No mass AI pages solely to capture keywords.
- Own data must include methodology, date, scope and limitations.
- If a claim is based on an external source, cite the primary source.
- If a claim is ours, preserve the evidence so others can cite AI ULTRA as the primary source.
