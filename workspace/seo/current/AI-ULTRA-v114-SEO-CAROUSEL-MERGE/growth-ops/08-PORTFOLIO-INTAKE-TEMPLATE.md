# Portfolio / case intake template

When portfolio information arrives, capture:

## Basics
- Project/client name (or anonymized label if required).
- Industry / geography.
- Date / duration.
- What AI ULTRA actually delivered.
- Team members/roles.

## Starting state
- Business problem.
- Existing stack/process.
- Baseline metrics available.

## Work
- Architecture / tools / integrations.
- Key decisions and alternatives rejected.
- Screenshots/demo materials available.
- Security/privacy constraints.

## Result
For each result mark evidence type:
- measured metric;
- client-reported metric;
- qualitative observation;
- modeled estimate.

Capture the exact period and denominator for every number.

## Reuse map
One case may generate:
1. portfolio page;
2. commercial-page proof block;
3. blog technical breakdown;
4. external expert article;
5. research datapoint (only if aggregation/privacy permits);
6. SMM/video creative;
7. sales deck proof;
8. FAQ/training material.
