# Launch gate — do not publish until these are green

## SEO / discovery
- Production domain approved and substituted everywhere.
- Production sitemap contains only intended indexable URLs.
- Canonical URLs use production domain.
- robots.txt allows search crawlers to fetch public pages.
- OAI-SearchBot remains crawlable on public pages intended for ChatGPT Search discovery/citation.
- Intentional noindex pages remain noindex after release.
- HTTP 200/301/404 behavior tested on real host.
- No staging host references in active HTML, JSON-LD, sitemap, robots, llms or redirects.

## Visual merge
- Final Three.js carousel engine frozen before integration.
- Raster textures do not replace critical live text.
- Important navigation exists as ordinary HTML <a> links.
- All front/back card copy has a live semantic HTML source.
- Mobile and desktop are tested separately.
- Graceful content access if WebGL fails.

## Measurement
- Yandex Metrica installed.
- Goals/events: lead submit, Telegram click, phone/email click if used, PDF lead-magnet start/completion, case-view, pricing interaction, CTA click, qualified-lead marker.
- UTM naming standard fixed before SMM/Direct launch.
- Consent/privacy copy matches actual tracking stack.

## Trust
- Real team information available when approved.
- Portfolio uses real project evidence only.
- Case claims have proof/source notes internally.
- Dates/owners for editorial and research content are explicit.

## Launch decision
Release only when SEO core + final visual engine + measurement stack pass together. Do not delay launch for post-launch moat items such as calculators, mass video or large research library.
