# AI ULTRA v110.1 CLEAN

This build is intentionally **STAGING-SAFE**.

- Production-indexable pages are `noindex,follow` while hosted on the temporary ChatGPT staging domain.
- Crawling is allowed so search engines can observe `noindex`.
- `sitemap.xml` is intentionally empty on staging.
- The original production sitemap is preserved as `sitemap.production.xml`.
- The original production robots file is preserved as `robots.production.txt`.
- Visible internal marker `SEO PURE — semantic HTML / no visual runtime` was removed.
- The internal `/blueprint/` link was removed from user-facing navigation.
- `SpeakableSpecification` / `speakable` markup was removed.
- Exact duplicated generic FAQ boilerplate was removed rather than replaced with invented copy.

## Production release

When the final domain is known, run:

```bash
python release-production.py https://YOUR-DOMAIN.TLD
```

Then validate the generated `sitemap.xml`, `robots.txt`, canonical URLs and redirect map before deployment.
